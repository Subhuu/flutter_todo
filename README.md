## 🚀 Key Features

*   **💎 Glassmorphism Design**: Frosted glass effects using `BackdropFilter` and semi-transparent layers.
*   **📱 Highly Responsive**: Adapts gracefully to different screen sizes and orientations.
*   **💾 Local Persistence**: Data streams are saved locally using `SharedPreferences`, ensuring your tasks are safe even when offline.
*   **✨ Smooth Animations**: Interactive hover and tap effects using `AnimatedContainer` and custom transitions.
*   **✏️ CRUD Operations**: Create, Read, Update, and Delete tasks with intuitive gestures.

## 🛠️ Tech Stack

*   **Framework**: [Flutter](https://flutter.dev/) (SDK 3.x)
*   **Language**: [Dart](https://dart.dev/)
*   **State Management**: `StatefulWidget` (Native)
*   **Storage**: `shared_preferences`
*   **Architecture**: Modular (Separation of Concerns: Service, Model, View)

## 🏁 Getting Started

### Prerequisites

*   [Flutter SDK](https://docs.flutter.dev/get-started/install) installed.
*   Android Studio or VS Code configured.

### Installation

1.  **Clone the valid repo**
    ```sh
    git clone https://github.com/Subhuu/flutter_todo.git
    ```
2.  **Install dependencies**
    ```sh
    cd flutter_todo
    flutter pub get
    ```
3.  **Run the app**
    ```sh
    flutter run
    ```
